## 核心需求

**目标**：实时预览式编辑的 Markdown 插件，同时保留 VS Code 内其他插件的代码补全能力（所以基于原生编辑器 + Decoration，即路线 A）。

**基础功能**

| # | 需求 | 实现方式 | 可行性 |
|---|---|---|---|
| 1 | 粗体、下划线、斜体直接渲染，光标所在行才显示标记符 | Decoration 隐藏标记符 + 样式 | 可行，粗体已验证 |
| 2 | 标题自定义颜色、粗体/斜体、字体选择（不做字号） | 按 h1 到 h6 分别建 Decoration，读取用户配置 | 颜色、粗体、斜体是官方支持；字体选择要靠 CSS 注入，需实测 |
| 3 | 代码块、引用块背景色与正文区分 | `isWholeLine` 整行背景 | 可行 |
| 4 | 表格、Mermaid、引用图片的浮动预览 | HoverProvider | 见下方说明 |

**进阶功能**

| # | 需求 | 实现方式 | 可行性 |
|---|---|---|---|
| 5 | 行内公式渲染 | SVG 转图片，替换 `$...$` 显示 | 可行，高公式可能和相邻行重叠 |
| 6 | 多行公式渲染 | 悬停预览或侧边预览 | 原位内联渲染做不到，只能浮动显示 |

## 需要提前说明的几点

- **下划线**：标准 Markdown 没有下划线语法，通常是 `<u>文字</u>` 这种 HTML 写法（有些方言用 `++文字++`）。你想用哪种写法，需要先定。
- **图片预览**：本地和网络图片放进悬停浮窗最简单，应该没问题。
- **表格预览**：我之前说过，浮窗里能否渲染表格需要先用小 demo 验证。
- **Mermaid 预览**是第 4 项里最难的一块。Mermaid 需要浏览器环境才能把代码画成图，而悬停浮窗里不能跑脚本，所以得先在后台把它渲染成 SVG 图片再放进浮窗，常见做法是调用 mermaid-cli（会带上一个无头浏览器，比较重）。做不顺的话，退路是侧边预览面板。
- **字体选择**可能受限：CSS 注入的写法不是官方支持的，加上等宽编辑器对非等宽字体的光标定位不太友好，建议等到后面单独试。

## 建议的实现顺序

1. 在现有 TS 版本上补全：斜体、下划线、标题配色、代码块和引用块背景（全是官方 API 或简单 hack，风险低）。
2. 用小 demo 验证悬停浮窗：先试表格和图片。
3. 行内公式。
4. Mermaid 和多行公式的浮动预览，最后做。
